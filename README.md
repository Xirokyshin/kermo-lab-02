# Автосалон «Кермо»

Навчальний односторінковий сайт автосалону у Львові.

**Демо:** [Автосалон «Кермо» на GitHub Pages](https://xirokyshin.github.io/kermo-lab-02/)

## Що є на сайті

- Адаптивна верстка від 320 до 1920 px і бургер-меню на чистому CSS.
- Каталог автомобілів, фонове фото та відео.
- Таблиця умов кредитування, три пакети підбору авто й форма запису на тест-драйв через Formspree.
- Плавні переходи, анімація появи першого екрана й режим зменшеного руху.

## Технології

HTML5, CSS, Flexbox, медіазапити та CSS-анімації. Для локального перегляду відкрийте `index.html` або запустіть Live Server у VS Code.

## Структура

- `index.html` — головна сторінка.
- `css/style.css` — стилі та анімації.
- `img/` — зображення та іконки.
- `video/` — фонове відео.
- `fonts/` — локальний шрифт Onest і його ліцензія.
