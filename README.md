# Автосалон «Кермо» — лабораторні №2–4

Проєкт для VS Code: чисті HTML і CSS, без JavaScript, фреймворків і збірки.
Звірено через офіційний Figma MCP із файлом WEB1:
https://www.figma.com/design/O22HB8yUT550W2azWDY4K7/WEB1?node-id=0-1

Макети: Desktop — 1440 (1:2), Mobile — 375 (1:169).

## Запуск

Відкрийте папку проєкту у VS Code. Для index.html виберіть Open with Live Server.
Або відкрийте index.html у браузері подвійним натисканням. Усі потрібні файли,
включно зі шрифтами й відео, локальні. npm install не потрібний.

## Структура

- index.html — семантична розмітка та посилання.
- css/style.css — база, кольори, Flexbox, медіафони та медіазапити.
- img/ — фото WebP, карта та SVG-іконки.
- fonts/ — Onest Regular і Bold, ліцензія OFL.txt.
- video/showroom-car.mp4 — фонове відео без звукової доріжки.
- .vscode/ — UTF-8, відступи та рекомендація Live Server.

## Що взято безпосередньо з Figma

Шрифт Onest (400/700), палітра, розміри заголовків, міжрядкові інтервали,
інтервали між літерами, ширина контейнера, відступи, колонки автомобілів,
вигляд логотипа, розташування відгуків, карта й іконки. Логотип у макеті
складено з тексту та кольорових частин; у HTML його відтворено тими самими
елементами й шрифтом. Оригінальні фото та SVG-іконки завантажено через
Figma MCP; скриншоти не використовуються як зображення сторінки.

Фото оптимізовано у WebP із якістю 82. Фон підготовлено в ширині 1920 px,
автомобілі — 760 px. Карта збережена без втрат у розмірі 1176×512.
Оригінальні SVG-іконки зберігають власні розміри 40×40.

При ширині 1440 px висоти секцій відповідають Figma:

## Лабораторна №2

Методичка: https://9.lviv.ua/academy/web-development/html-css-flexbox/

Застосовано header, nav, main, section, article, footer, address і логічну
послідовність h1 → h2 → h3. Є один h1. У head задано UTF-8, viewport,
title (56 символів) та description (160 символів). Усі стилі — в окремому
CSS; глобально задано border-box, кольори — у :root. Розкладка на Flexbox,
без Grid, float, таблиць для розкладки, абсолютних координат для основного
вмісту чи копіювання згенерованого коду Figma. Позиціювання використано
для фонів, бургера та випадаючого меню.

## Лабораторна №3

Методичка: https://9.lviv.ua/academy/web-development/responsive-burger-menu/

Після базових правил стоять медіазапити 1200, 900 і 600 px. На вузькому
екрані колонки перебудовуються, автомобілі стають картками.

Мобільне меню працює без JavaScript через фрагмент адреси та :target.
Посилання .burger--open веде до #primary-nav. Правило .nav:target показує
навігацію, ховає посилання відкриття й показує хрестик .burger--close.
Вибір пункту змінює фрагмент на #cars, #inspection, #finance, #reviews або
#contacts, тому меню автоматично ховається. Хрестик веде до #site-header.

Клавіатура: Tab вибирає посилання, Enter активує його. Після відкриття
фокус переходить до nav з tabindex="-1", наступний Tab знаходить перший
пункт. Закриті посилання не потрапляють до обходу завдяки visibility: hidden.
Space не використовується як клавіша активації, оскільки керування побудоване
на посиланнях. Checkbox і :checked у поточному коді відсутні.

Цей спосіб відрізняється від прикладу з checkbox у методичці й обраний
користувачем для автозакриття без JavaScript. Стан видно у частині адреси
після #; кнопка браузера «Назад» може повернути попередній стан меню.
Закриття Esc і динамічне aria-expanded не реалізовані.

Основний мобільний текст має розмір не менше 16 px. Бургер має область
48×48 px, видимі мобільні посилання — 44×44 px або більше.

## Лабораторна №4

Методичка: https://9.lviv.ua/academy/web-development/images-video/

Фотофон застосовано до наявної hero, відеофон — до наявної finance.
Нових секцій немає. Фотофон використовує оригінальний кадр автосалону з Figma,
background-size: cover та затемнення ::before. Білий текст і кнопка підняті
над фоном. Для головного фону задано preload з високим пріоритетом.

MP4/H.264: 1280×720, 8,458 секунди, 2 307 847 байтів, без звукової доріжки.
Задані autoplay, muted, loop, playsinline, poster; object-fit: cover.
Постер — кадр цього самого відео, також використаний як CSS-фон.
При prefers-reduced-motion: reduce показується постер. У source задано
media="(prefers-reduced-motion: no-preference)"; у перевіреному Edge при
початковому reduce відеофайл не запитувався. Це не гарантує автовідтворення
на кожному пристрої: браузер може його обмежити, тому статичний фон необхідний.

Усі img мають alt, width і height, що відповідають реальним розмірам файлів.
Зображення нижче першого екрана мають loading="lazy" і decoding="async".
Жодне зображення не перевищує 300 КБ. Файли HTML/CSS, зображення, локальні
шрифти та MP4 разом займають приблизно 2,92 МБ — у межах орієнтирів методички.

## Свідомі відмінності від початкових макетів

Вимоги лабораторних і погоджені зміни мають пріоритет там, де вони
суперечать статичній картинці макета:

- У Figma hero жовта з окремим фото, finance синя. У проєкті це фотофон
  і відеофон із затемненням, як потрібно для №4; розміри та зміст збережено.
- У мобільному Figma немає вступу до перевірок і двох відгуків. На сайті
  вони доступні, щоб виконати вимогу №3 про однаковий зміст на різних екранах.
- Характеристики автомобілів на мобільному збільшено з 14 до 16 px для
  читабельності за №3. Через це на деяких ширинах текст займає більше рядків.
- Області натискання телефону та посилань збільшено до щонайменше 44 px.
- Instagram, Facebook і Telegram — робочі посилання на стандартні сторінки
  сервісів, як окремо попросив користувач.

Тому це реалізація за параметрами Figma з вимогами №2–4, а не обіцянка
піксельної тотожності початковому макету в усіх блоках.

## Перевірки

Перевірено в Edge через локальний HTTP-сервер на 17 ширинах: 320, 360, 375,
414, 599, 600, 601, 768, 899, 900, 901, 1024, 1199, 1200, 1201, 1440, 1920 px.
Перевірено завантаження Onest, відсутність переповнення і перекриття шапки,
зображення, іконки 40×40, клавіатурне меню, переходи, описи авто, відео
та режим зменшення руху. У перевірці немає помилок виконання чи HTTP-помилок.

Для перевірки Network: F12 → Network → Disable cache → оновити → прокрутити
сторінку донизу. Для перевірки системного reduce: DevTools → Rendering →
Emulate CSS media feature prefers-reduced-motion → reduce.

На фізичному телефоні й реальному мобільному з’єднанні сайт ще треба перевірити.
Підключіть телефон і ПК до однієї Wi-Fi мережі, запустіть Live Server,
дізнайтеся IPv4 ПК через ipconfig та відкрийте http://АДРЕСА-ПК:5500 на телефоні.

## Поведінка посилань

Меню переходить до секцій. Детальніше показує відповідний опис через :target.
Кнопки запису та кредиту використовують навчальний телефон із макета;
серверної форми, бронювання або кредитного калькулятора немає.
Карта відкриває пошук адреси у Google Maps. Соцмережі відкриваються в нових вкладках.
